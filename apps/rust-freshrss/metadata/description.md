## RustFreshRss

Interface web em Rust para trabalhar com entradas do FreshRSS usando cache local SQLite.

### Principais recursos

* Sincronização incremental com FreshRSS
* Filtros, stars, replacers e skippers
* Histórico de processamento
* Exportação e importação de regras
