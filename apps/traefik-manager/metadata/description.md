# Traefik Manager

Traefik Manager is a clean, self-hosted web UI for managing Traefik reverse proxies without editing YAML files by hand.

## Features

- Create and manage HTTP, TCP, and UDP routes
- Configure middlewares with guided wizards or raw YAML
- Monitor services, certificates, logs, and Traefik status
- Manage multiple Traefik servers through remote agents
- Create local and Git-backed configuration backups
- Optional static configuration, certificate, and access-log management

See the [project documentation](https://traefik-manager.xyzlab.dev/) for setup details and optional volume mappings.
