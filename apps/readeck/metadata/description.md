# Readeck

Readeck is a self-hosted read-later application for saving web articles and reading them later in a clean, distraction-free interface.

## Features

- Save and archive articles for later
- Extracts readable content from web pages
- Organize bookmarks with labels and filters
- Full-text search across saved content
- Export saved articles, including EPUB
- Browser extension and API support

## Getting Started

1. Open Readeck at the configured Runtipi port.
2. Create your account during the first-run setup.
3. Save articles using the web interface or browser extension.

## Documentation

See the [official Readeck documentation](https://readeck.org/en/docs/) for configuration, backups, and browser integrations.
