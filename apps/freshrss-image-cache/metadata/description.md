# FreshRSS Image Cache Service

Persistent, disk-backed image cache designed for the [FreshRSS Image Cache plugin](https://github.com/Victrid/freshrss-image-cache-plugin). It supports both the plugin's proactive `POST` requests and image `GET` requests.

Images are stored persistently in the app data directory. The service does not expire or automatically delete cached images, so storage use grows over time. Remove old cache files manually when needed.

The access token is generated by Runtipi. Copy it into the plugin's **Access Token** field. Configure the plugin with:

- **Cache URL:** `http://<RUNTIPI_HOST>:8875/?url=`
- **Proactive Cache URL:** `http://<RUNTIPI_HOST>:8875/`
- **Enable proactive cache:** enabled

Replace `<RUNTIPI_HOST>` with an address reachable from the FreshRSS container. Keep this service on a trusted network: the image `GET` endpoint accepts URLs without authentication and can fetch remote images.
