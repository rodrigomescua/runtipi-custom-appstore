# html2rss

html2rss turns almost any website into an RSS or JSON feed. Configure a source, let the scraper extract its content, and serve the resulting feed instantly from a self-hosted web application.

## Features

- Automatic website scraping
- RSS and JSON feed output
- Feed configuration and management through a web UI
- Browser-friendly feed endpoints
- Built-in scraper service for dynamic websites

## Getting Started

1. Open html2rss at the configured Runtipi port.
2. Complete the initial setup using the generated application credentials.
3. Add a website source and configure its feed.
4. Subscribe to the generated RSS or JSON endpoint.

## Documentation
